\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This thesis presents a fully local Retrieval-Augmented Generation (RAG)
chatbot designed to answer Vietnamese Human Resources (HR) policy-related
questions. A total of 20 HR policy documents were processed and indexed using
multilingual sentence embeddings and ChromaDB. The proposed system applies a
hybrid retrieval approach that combines dense similarity search and BM25
ranking using Reciprocal Rank Fusion (RRF). The retrieved relevant passages
are then provided to a Phi-3-Mini GGUF language model to generate responses.
In a small retrieval evaluation with 10 manually labelled queries, the hybrid
retrieval method achieved 100\% top-1 accuracy, while the dense retrieval
baseline achieved 60\%.

This study also explores domain adaptation through model fine-tuning. The
Qwen2.5-72B-Instruct model was used to generate 4,900 unique question-answer
pairs covering 20 HR policy topics. A keyword-based validation process showed
that 82.4\% of the generated questions were clearly related to HR topics, with
no exact duplicate questions or predefined irrelevant cases detected. QLoRA
fine-tuning was performed on an H200 GPU and completed three training epochs
in 5.3 minutes. For 20 direct questions without retrieval support, the
fine-tuned model improved the automated format and relevance score from 0.62
to 0.70, while reducing the average response time from 3.9 seconds to 0.9
seconds.

However, manual evaluation still identified incorrect policy information and
inconsistent answers. Therefore, the automated evaluation score cannot be
considered sufficient evidence of factual correctness. The final system keeps
RAG as the main approach for reliable knowledge retrieval, while fine-tuning
is used as an additional improvement method. The experimental results
demonstrate that hybrid retrieval provides better matching performance for
short queries, and that data quality and evaluation methods are important
factors in building reliable local AI assistants.

\vspace{0.5cm}
\noindent\textbf{Keywords:} Retrieval-Augmented Generation, Vietnamese NLP,
BM25, Reciprocal Rank Fusion, QLoRA, Local Language Model.

\chapter{Introduction}

\section{Context and Problem}
Company policies are frequently distributed as long PDF handbooks. Employees
must locate rules on leave, salary, insurance, remote work, or disciplinary
procedures, while HR staff repeatedly answer similar questions. Keyword search
helps only when users know the exact wording used by the document. The problem
is harder in Vietnamese because short colloquial questions may omit formal
policy terms.

Cloud language models offer fluent interaction but can expose confidential
documents, require network access, and introduce recurring cost. A local system
avoids these constraints, yet a small model cannot be expected to memorize each
company's policy or reliably infer facts from its parameters. RAG addresses
this limitation by retrieving relevant passages at query time and conditioning
generation on those passages \cite{lewis2020rag}.

This work asks whether a compact, offline pipeline can retrieve Vietnamese HR
policy passages accurately enough to support a local responder. It also asks
whether QLoRA domain adaptation improves a small model when trained on a
quality-gated synthetic dataset. The second question is deliberately separated
from deployment: an ungrounded model may produce plausible but incorrect policy
values even when its language and speed improve.

\section{Related Work}
RAG combines non-parametric retrieval with neural generation, allowing evidence
to be updated without retraining \cite{lewis2020rag}. Dense retrievers encode
queries and passages into a vector space. Sentence-BERT made this practical for
semantic similarity \cite{reimers2019sbert}, while multilingual encoders extend
the approach across languages.

BM25 remains a strong lexical ranking method \cite{robertson2009bm25}. Dense
retrieval captures meaning but may miss exact terms in short queries; BM25 has
the opposite strengths. Reciprocal Rank Fusion (RRF) combines ranked lists
without requiring calibrated scores \cite{cormack2009rrf}. This makes it useful
when vector similarity and BM25 scores have different scales.

Phi-3-Mini is a compact instruction-tuned model intended for constrained local
deployment \cite{phi3technical2024}. LoRA adds trainable low-rank matrices while
freezing base weights \cite{hu2022lora}; QLoRA applies this method to a quantized
base model to reduce training memory \cite{dettmers2023qlora}. These techniques
make adaptation affordable, but they do not guarantee that synthetic labels are
correct or that automatic relevance checks measure factual accuracy.

Vietnamese introduces additional retrieval difficulty because whitespace does
not always correspond to word boundaries. PhoBERT illustrates the value of
language-aware pretraining for Vietnamese NLP \cite{nguyen2020phobert}, while
ViQuAD provides a reference point for Vietnamese machine-reading evaluation
\cite{viquad2020}. The present implementation uses a multilingual encoder and
simple whitespace BM25 tokenization, which is efficient but remains a limitation.

\section{Contributions}
The main contributions of this thesis are summarized as follows:
\begin{enumerate}[leftmargin=1.2cm,itemsep=2pt]
  \item \textbf{Private and Offline Vietnamese HR RAG Pipeline:} This thesis
        develops a private, offline RAG pipeline for Vietnamese HR knowledge
        retrieval, integrating local embeddings, ChromaDB, hybrid retrieval,
        and Phi-3-Mini GGUF inference.
  \item \textbf{Dense and Hybrid Retrieval Comparison:} This thesis compares
        dense and hybrid retrieval methods for short Vietnamese HR queries in
        an internal chatbot scenario.
  \item \textbf{Quality-Gated Vietnamese HR Q\&A Dataset:} This thesis constructs
        a quality-gated dataset of 4,900 unique Vietnamese HR question-answer
        pairs for chatbot evaluation and experimentation.
  \item \textbf{H200 QLoRA Fine-Tuning Experiment:} This thesis conducts a
        measured QLoRA experiment on the H200 platform using Python and
        JSON-based evaluation workflows, while distinguishing automated
        relevance indicators from factual policy correctness.
\end{enumerate}

\section{Research Questions and Scope}
The evaluation is structured around three research questions. \textbf{RQ1}
examines whether the combination of lexical and dense rankings improves
top-document retrieval for short Vietnamese HR questions. \textbf{RQ2}
investigates whether a controlled synthetic dataset can shift Phi-3-Mini toward
Vietnamese HR-specific language while reducing direct inference latency.
\textbf{RQ3} assesses whether automated evaluation indicators are sufficient to
determine factual policy correctness.

RQ1 is addressed through a paired comparison using the same ten labeled queries.
RQ2 uses identical 20-question prompts for both the base and adapted models.
RQ3 requires manual inspection of the generated outputs and analysis of the
scoring code. The scope of this thesis does not include legal assessment,
deployment in a real company, or a formal human-subject study. This boundary is
important because a technically functional chatbot is not equivalent to a
validated HR decision-support system.

\chapter{Objectives}

The project has four objectives:
\begin{enumerate}[leftmargin=1.2cm,itemsep=3pt]
  \item Design and implement a fully local Vietnamese HR question-answering
        system in which source documents remain on the user's machine;
  \item Compare dense retrieval with BM25--vector fusion for short HR-related
        queries;
  \item Construct and validate a synthetic domain-specific dataset, then assess
        the QLoRA adaptation of Phi-3-Mini;
  \item Evaluate the system transparently, including incorrect outputs and the
        limitations of small test sets and heuristic metrics.
\end{enumerate}

The implemented architecture is considered successful when it retrieves a
relevant policy source, constructs a grounded prompt, and returns a Vietnamese
answer with a source reference. The fine-tuning experiment is evaluated
separately because its direct, retrieval-free test measures model adaptation
rather than end-to-end RAG correctness.

\chapter{Materials and Methods}

\section{System Architecture}
Figure~\ref{fig:architecture} illustrates the offline processing and query paths
of the proposed system. During indexing, Vietnamese HR policy documents are
split into overlapping chunks, embedded, and stored in ChromaDB. During
querying, vector retrieval and BM25 retrieval are performed over the same
document corpus. Reciprocal rank fusion (RRF) is then applied to select the
top-ranked passages, which are inserted into a Phi-3 chat prompt. The model is
executed through \texttt{llama-cpp-python}, ensuring that no company document is
sent to an external inference API.

\section{Hybrid Retrieval}
Dense search retrieves semantically related text, while BM25 emphasizes exact
query-term matching. To combine the advantages of both methods, their ranked
lists are fused using reciprocal rank fusion (RRF), defined as follows:
\begin{equation}
S(d) = \alpha \frac{1}{k + r_v(d) + 1} + (1 - \alpha) \frac{1}{k + r_b(d) + 1},
\label{eq:rrf}
\end{equation}
where $r_v$ and $r_b$ are the vector and BM25 ranks, $k = 60$, and
$\alpha = 0.5$. The implementation returns a configurable top-$k$ context; the
deployed answer path defaults to three chunks. Because RRF uses ranks rather
than raw scores, no cross-system score calibration is needed.

\section{Answer Generation}
The responder uses Phi-3-Mini-4k-Instruct in GGUF Q4\_K\_M format
\cite{phi3technical2024}. The prompt includes a Vietnamese instruction,
retrieved chunks with source labels, and the user question formatted with
Phi-3 chat tokens. Generation is configured with a low temperature and stops
at the model's chat boundary. Source grounding is achieved through the retrieved
context and prompt structure, rather than by assuming that the model parameters
contain correct company-specific rules.

\section{Implementation and Privacy Controls}
The implementation separates ingestion, retrieval, and generation into Python
modules. PDF extraction and chunking produce serializable records; the embedding
module manages the ChromaDB collection; the hybrid retriever uses the same chunk
set for both BM25 and vector ranking; and the responder wraps
\texttt{llama-cpp-python}. This modular design allows retrieval tests to be
performed without loading the 2.32~GB generator model and makes failure sources
easier to identify.

At startup, the application checks whether the GGUF model file and vector
collection are available. A user question is normalized, embedded, and sent to
both retrieval branches. The fused top-ranked passages, defaulting to three
context chunks in the answer path, are formatted with their source names before
local generation. The interface returns the generated text together with source
metadata, allowing the user to inspect the underlying policy rather than treating
the model output as an authoritative decision.

Privacy follows from the local data flow: policy text, embeddings, prompts, and
answers remain on the machine during normal operation. External computers were
used only to create the synthetic research dataset and train the adapter; it was
not part of the deployed inference path. A real organization would additionally
require access control, encrypted storage, audit logging, retention policies,
and review procedures for uploaded documents. These controls are outside the
prototype scope but are necessary before production use.

The principal failure control is prompt-instructed abstention when the retrieved
context is insufficient. However, this mechanism is weaker than formal entailment
verification. Source display therefore remains important, especially for
numerical benefits or legal questions. No model response should replace an
approved policy document or professional HR judgment.

\section{Synthetic Data Generation and Validation}
An initial fine-tuning attempt used a web-crawled dataset that mixed unrelated
material with HR content. Its outputs included references to Medicare and other
off-domain subjects. Rather than treating that run as representative of QLoRA,
the experiment was repeated with data generated only from the 20 controlled HR
documents.

Qwen2.5-72B-Instruct-AWQ ran with vLLM on a Vast.ai H200. Prompts requested
natural Vietnamese questions and source-grounded answers for each document.
Generation resumed by document and batch, normalized questions were deduplicated,
and the accepted output stopped at the available final total of 4,900 pairs.

Validation checked JSON structure, length, exact normalized question duplicates,
predefined off-domain red flags, and a Vietnamese HR keyword set. These checks
are reproducible but shallow: a pair labelled ``unclear'' may still be relevant,
and a pair containing an HR keyword may still contain a wrong policy value.

\section{Evaluation Protocol}
Retrieval and generation were evaluated separately to avoid attributing one
component's failure to another. The retrieval set paired ten questions with a
gold source-document label. Accuracy@1 and Mean Reciprocal Rank were calculated
as:
\begin{equation}
\mathrm{Acc@1} = \frac{1}{N} \sum_{i=1}^{N} \mathbb{1}[r_i = 1], \qquad
\mathrm{MRR} = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{r_i},
\label{eq:metrics}
\end{equation}
where $r_i$ is the rank of the labelled document. Dense and hybrid retrieval
used the same corpus and queries.

For direct generation, each model received the same 20 questions and no policy
context. Decoding was deterministic. The scoring function checked HR-keyword
presence, Vietnamese-character frequency, minimum length, and eight literal
off-domain/refusal flags. Latency measured one generation call on the H200
evaluation environment. Since answer correctness was not compared with a
structured gold answer, manual error analysis is reported alongside the score.

The two evaluations answer different questions. Retrieval metrics measure
whether evidence can be found; direct generation metrics measure topical form
and speed after adaptation. Neither alone measures end-to-end user trust. A
complete future protocol should combine retrieval, source-grounded generation,
factual scoring, and human review on a larger held-out set.

All evaluation scripts are implemented in Python 3.10. The retrieval and
generation tests use \texttt{pandas} for data aggregation, the built-in
\texttt{re} module for keyword matching, and \texttt{time} for latency
measurement. Input queries and outputs are stored in JSONL format to ensure
reproducibility. The scoring logic is encapsulated in
\texttt{scripts/validate\_qa.py} and \texttt{src/hybrid\_retriever.py}, as
listed in Appendix~A.

\chapter{Results and Discussion}

\section{Retrieval Results}
The internal retrieval test contains ten Vietnamese HR questions with manually
assigned source documents. Dense search returned the correct top document for
six questions, while hybrid retrieval returned it for all ten. MRR improved
from 0.72 to 1.00 (Table~\ref{tab:retrieval-results}). This is evidence for the
tested queries, not a population-level accuracy estimate.

The largest gains occurred for brief queries such as ``one month has how many

not replace semantic retrieval. The main uncertainty is sample size: ten
questions cannot establish robustness across all employee language.

paraphrases, limited coverage of numeric facts, and a small model learning
surface patterns rather than source-grounded reasoning.

\section{Role of RAG After Fine-Tuning}
The direct evaluation intentionally omitted retrieval, whereas the deployed
system supplies policy passages. Fine-tuning and RAG answer different needs:
fine-tuning can improve register, response structure, and domain vocabulary;
RAG supplies current facts and source attribution. The observed factual errors
support keeping retrieval as the authority. A future comparison should run the
base and fine-tuned GGUF models through the identical RAG pipeline and score
answers against source-derived references.

Figure~\ref{fig:demo} shows the local CLI after rebuilding the controlled
Vietnamese index. The statistics view exposes the model file, 258 indexed chunks,
embedding dimension, and hybrid retrieval configuration. During normal question
answering, source labels allow users to verify an answer; this is more defensible
than presenting model confidence as policy correctness.

\section{Limitations and Threats to Validity}
This study has three main limitations:
\begin{itemize}[leftmargin=1.2cm,itemsep=2pt]
  \item \textbf{Synthetic Data and Limited Verification:} The corpus is based on
        demonstration HR policies rather than an approved handbook from a real
        company. In addition, the generated Q\&A pairs were not exhaustively
        verified against every source sentence.
  \item \textbf{Small-Scale and Heuristic Evaluation:} The retrieval and
        generation evaluations use small test sets, and the automated checks
        mainly measure topical relevance rather than factual correctness,
        entailment, or legal validity.
  \item \textbf{Prototype-Level Deployment Constraints:} The system has not been
        deployed in a real company environment. Practical concerns such as
        access control, audit logging, secure storage, Vietnamese tokenization
        quality, and hardware dependence remain outside the current prototype
        scope.
\end{itemize}

\chapter{Conclusion and Perspective}

This project implemented a private Vietnamese HR assistant in which the
documents, retrieval index, and language model run locally. Hybrid BM25--vector
retrieval improved top-1 source selection from 6/10 to 10/10 on a small internal
test, showing that lexical and semantic rankings are complementary for short
queries.

The H200 experiment generated 4,900 unique Q\&A pairs and trained a Phi-3-Mini
QLoRA adapter in 5.3 minutes. Fine-tuning improved the automated topicality and
format score and reduced direct inference latency; however, manual inspection
still found incorrect policy facts. Therefore, the main conclusion is not that
fine-tuning solved factual accuracy. Instead, controlled data generation made
the model more domain-focused, while retrieval remained necessary to provide
authoritative and inspectable facts.

Future work should include: (1) linking each generated answer to an exact
supporting span, (2) using source-grounded reference answers and human HR review,
(3) comparing base and fine-tuned GGUF models within the same RAG pipeline,
(4) adopting Vietnamese word segmentation for BM25, and (5) testing the system
with an approved real-company handbook. These steps would help transform the
current proof of concept into a more credible evaluation of practical HR policy
assistance.
