**Defined:** 2026-06-22
**Milestone:** v1.1 Report Revision and Finalization
**Core Value:** Employees receive grounded Vietnamese HR answers from local policy documents without cloud data exposure.

## v1.1 Requirements

### Evidence

- [x] **EVID-01**: The thesis reports the generated dataset as 4,900 unique Q&A pairs across 20 source documents.
- [x] **EVID-02**: Dataset quality claims match validation output: 82.4% keyword-based domain relevance, 863 unclear pairs, zero red flags, and zero exact duplicate questions.
- [x] **EVID-03**: Fine-tuning configuration and timing claims are traceable to `finetune_run.log` and the saved adapter/GGUF artifacts.
- [x] **EVID-04**: The base/fine-tuned comparison matches `data/eval_report.txt` and clearly labels its automated scoring limitations.

### Narrative

- [x] **NARR-01**: The report replaces the obsolete QLoRA-only negative-result narrative with a chronological account of the failed first dataset and the quality-gated H200 rerun.
- [x] **NARR-02**: The discussion distinguishes faster generation and heuristic relevance from factual policy correctness.
- [x] **NARR-03**: Abstract, objectives, methods, results, conclusion, tables, and captions use mutually consistent statistics and conclusions.

### Length

- [x] **LEN-01**: The compiled thesis is approximately 27 total pages.
- [x] **LEN-02**: Repetition, verbose background, full code listings, and full raw evaluation appendices are removed before any typographic compression is considered.
- [x] **LEN-03**: Required front matter, core method explanation, central results, references, and essential figures remain legible and present.

### Verification

- [x] **VER-01**: `report/thesis.tex` compiles without fatal LaTeX errors.
- [x] **VER-02**: The final PDF page count is measured rather than estimated.
- [x] **VER-03**: A final search finds no stale central claims such as 3,343-only training data, 22-hour-only training, or an unqualified claim of zero hallucinations.
